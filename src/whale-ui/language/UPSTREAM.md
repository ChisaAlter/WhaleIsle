# Owned language source

The language, parser, library and runtime TypeScript started from OpenUI SDK `@openuidev/lang-core` 1.0.0, commit `f7109dd01b7bdfb14c8c9006eaca5a8b3cfc3a20` (MIT). Original TS came from the installed package's `index.mjs.map` `sourcesContent`; the omitted token and export barrels were recovered from the same fixed upstream revision. See [LICENSE](./LICENSE).

Whale UI maintains these files directly. Its build imports `index.ts`, never the donor's compiled output. Telemetry, installation hooks and cloud entrypoints were excluded. Local library functions, runtime parser, prompt/schema generation and the provider-neutral Query/Mutation interface remain available. The viewer supplies no business tool provider.

Local repairs include explicit settled incomplete/unresolved diagnostics, Unicode identifiers and quoted object-key serialization, literal-only state defaults, bounded parsing/materialization/evaluation/rendering/store work, evaluated prop validation, deferred sequential actions and explicit null assignment semantics. Repeated declaration references share normalized expression nodes within one parse result. Each synchronous root/expression evaluation reuses successful pure data calculations locally; components, action plans, failed calculations and functions without an explicit `pure` contract are excluded. `pure: true` means deterministic data output without effects or argument mutation. First-party random/time functions do not opt in. Each substitutes only branches with free item references, preserving shared global expressions and nested lexical shadowing. Later renders, field updates and deferred action steps always evaluate in a fresh pass. Already-lowered reactive bindings stay opaque through repeated inline/Each prop traversal, so their expressions evaluate only on user edits.
