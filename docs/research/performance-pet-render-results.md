# 桌宠输出优化与体验评估（T16）

2026-10-09，候选 `C:/AI/WhaleIsle-application-performance`，基线 `26205a89`。没有修改模型、角色图、Anime4K 算法、透明边缘、命中区、50ms 正常 / 110ms 现有省电推理间隔或显示刷新节拍。

采用：WebGPU 将模型 CHW float32 输出转换为 packed RGBA8，再下载一帧 1MiB 数据。原先每帧下载 4MiB，之后由 CPU 重排并钳制。转换保持 Uint8ClampedArray 的钳制、NaN/Infinity 和半值舍入到偶数行为。WebNN/WASM 继续原转换；GPU 转换 pipeline 初始化不支持时沿用原 float 下载。两条路径都在下载失败时释放所有模型输出，保留上一显示帧并允许下一次推理。

选卡不绑定测试机：`createSession()`沿用运行时可用后端的选择，packed转换复用 `ort.env.webgpu.device`，没有显卡厂商、型号或适配器序号匹配。下述RTX3060仅记录实测硬件，不是产品配置或所有用户的目标；其他GPU的功能、画面与收益仍需分别验证。

512² 输出在 20fps 时的理论下载量从 80MiB/s 降为 20MiB/s。新转换持有两个 1MiB GPU buffer；未宣称整个进程或整机内存按比例下降。矩阵计算仍是主要 GPU 工作，没有升级 ORT、重新导出模型或强制所有应用窗口独显。

## 同条件实际可见渲染器测量

使用本候选原生产页面、pet:// 协议和 Electron 44.1.1，独立临时 profile。native 透明窗口 `showInactive`，不抢焦点、不接管鼠标；DPI 1.5，primary display 为 1707×960 DIP。GL renderer 是 RTX 3060 Laptop GPU，ORT WebGPU / 512² / Anime4K 均实际就绪。本机原路径已使用独显，未复现“走核显”。这个结果不能代替其他用户设备或原有安装实例的选卡结果。

为配对控制姿态与工作量，测量阶段停止该隔离窗口的 rAF，直接调用原生产 renderFrame，每 50ms 一次、每组 6 秒、三组交替。窗口真实可见；宿主 IPC、鼠标输入、自然 rAF/桌面合成及完整管理器用户路径未包含在这个配对指标内。

| 原始输出路径 | 三组推理和输出 p50 | 三组 p95 | 每秒实际完成 |
| --- | --- | --- | --- |
| float 下载 / CPU 重排 | 42.1 / 42.3 / 43.1ms | 45.3 / 46.9 / 46.5ms | 19.80–19.83 |
| packed GPU 转换 / 字节下载 | 33.6 / 33.6 / 34.4ms | 36.2 / 35.6 / 36.8ms | 19.82–19.84 |

中位 p50 改善约 20.6%。这表示处理帧的余量增加，不表示提高了用户配置的推理帧率。原始数据见 [performance-pet-render-measurements.json](./performance-pet-render-measurements.json)。

六个实际模型输出（零姿态和不同非零姿态）分别对一帧全部 1,048,576 字节比较，均 0 差异。额外真实 GPU 数据覆盖 NaN、正负 Infinity、负数、0.5/1.5/2.5/254.5 等半值，每字节 0 差异。显示仍通过原 putImageData / Anime4K / alpha 管线，未改变身体比例、眼形或锐化。截图已查看，角色有内容、位于窗口右下角、无白帧；完整拖拽/抛掷/投喂/菜单/聊天及跨屏须由统一候选验收补齐。

CPU 路径的 clamp 数据和失败时释放所有输出/恢复下一帧两个检查通过。原 renderer 相关 59 项在同版检查中通过；初次新增失败检查因夹具未设置 pose Tensor 先被拦住，补齐夹具后该检查通过，没有改弱断言。

## 体验影响与未采用方案

- 预计收益：输出下载和 CPU 重排负担下降，帧处理更早完成，既定动作节拍保持。
- 代价与边界：增加一个 GPU compute pass、两个常驻 buffer；不同设备/驱动仍需实际兼容观察。不能据本机抽样承诺所有画面或设备绝无变化。
- 没有采用矩阵 kernel/模型重导出、GPU 与 WebGL 直接共享、ORT/Anime4K 裁剪、稳定气泡缓存或重复 paint 合并。它们各有精度/支持/布局或历史闪烁风险，当前采用的路径已有可测收益，先完成组合验收。
- 默认选卡没有改变。本机已是独显；双 GPU 的 Windows 偏好与其他设备兼容仍未验证。

本报告是渲染器配对与字节等价证据，不是完整安装包或用户体验完成声明。
