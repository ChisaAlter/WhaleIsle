## 当前体验结论

已经实现可测的计算、读盘和查询热点；没有用降帧、降低分辨率/锐化、截断日志/消息、延迟新草稿保存或关闭后台任务换取性能。桌宠实际运行独显、20次窗口生命周期、通知一次投递、64目录搜索、真实大文件写盘及30分钟正常退出有对应证据，见 [组合观察](./performance-combined-results.md)。旧主UI样本未同步记录原生主窗可见性，renderer截图只证明其渲染内容，未当作完整原生窗口视觉通过。

确有体验取舍的采用项是：T02首次worker冷扫描完成可能更晚；T06/T07异步读盘减少卡顿但不保证扫描/安装总等待更短；T08取消仍需等已发IPC结束；T13超载时有效抓帧率更低、重开需等待旧抓帧；T16多一个compute pass与2MiB GPU buffer。这些边界已经记录，不能回答“保证完全没有影响”。

候选保留在独立工作分支。包含最后preload修正的完整目录包已构建并实际启动，基础启动/首次提取/API/PTY通过，右栏布局探针仍失败，最终smoke为exit1。完整QA和视觉验收没有全部通过，失败未隐藏；性能验收阶段没有替换用户日常版本、制作NSIS、提交、推送、创建PR或发布。剩余右栏/设置/恢复和真实PiP须先区分环境、基线或本轮回归；长历史完整功能诊断已通过，但缺少热点因果profile，保留原实现。局部函数对照不能推出整应用CPU、内存、能耗或响应p95已改善。
