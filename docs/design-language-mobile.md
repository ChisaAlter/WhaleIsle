# DSHD 设计语言：手机远程交互

中文 | [English](design-language-mobile.en.md)

本文是 [design-language.md](design-language.md)「手机远程交互」节的完整契约；token 总表、强制规则与例外以母文档为准。2026-10-25 用户要求手机端尽量接近桌面，替代[旧 Claude 式结构](decisions/implemented/product/2026-09-24-mobile-remote-claude-structure.md)中的圆角抽屉、最近导航、衬线品牌和短操作全屏页。

远程 Web 与 Android 共用桌面鲸屿的信息层级、颜色、字体栈和语义 token。画布与侧栏各取对应的基线角色；不引入第二套产品皮肤。Web 使用镜像 `--dsw-alias-*` / `--dsw-specific-*`，Android 使用同值 `DshTokens`。品牌头像使用 `assets/whale-head.png` 的同源透明图，与「鲸屿 / WHALE ISLE」及「BASED ON DEEPSEEK HARNESS」字标组合；不得用简笔鲸鱼或 emoji 替代。中文主字标仅「屿」使用品牌蓝，头像不加方形底板。

## 连接入口

连接、相机权限和扫码入口保留鲸屿海天关系，不复制桌面启动状态、日志、窗口按钮或 `--boot-*` 名称。品牌是紧凑头像和产品字标，使用系统界面字体；不再将巨型展示衬线作为手机品牌。浅深主题使用 `--mobile-connect-*` 与 Compose `DshTokens` 的同义表。首次打开且没有保存外观时跟随系统明暗。Android 首次配对或从连接入口重连时，认证、目录及当前会话的历史和控制项就绪后才进入聊天；连接中、失败、取消均保留在连接入口。已有聊天的同电脑断线恢复保留原任务面。

连接首屏承载一个「扫描二维码」主按钮、一个「粘贴配对链接」次入口和已保存电脑重连。粘贴字段只在选择后展开；从权限页或原生扫码选择粘贴时，返回后立即展开并聚焦。保存电脑以可重连的紧凑行显示，名称为主、连接端点为次，忘记有独立命中区。名称优先取 `server_info.hostname`，旧记录无名称时显示「我的电脑」，内部 `serverId` 不作名称。Web sticky 与 Android 加密库保持既有身份，不为视觉整理删除凭据。

首次连接和重连在原状态槽显示「正在连接电脑…」，失败恢复按钮并保留设备。长错误用紧凑浮层呈现，不能遮盖品牌和主操作，重试入口在浮层消失后仍可达；普通失败浮层不带关闭按钮。认证成功后的目录和会话同步有真实状态，失败不能冒充空目录；Android 在连接入口就地展示错误、重试与取消。Android 主 Activity 强制竖屏；Web 的 320px、竖屏、横屏与安全区均保留可达操作。

## 侧栏与会话

侧栏从左边贴边展开，四角为直角，使用发丝分隔线。顶部为桌面同源品牌与关闭入口，下面是横向占满可用宽度的「新会话」。目录直接按工作区分组呈现会话，保留搜索、工作区管理、归档、运行状态和行菜单；不用「会话 / 工作区 / 设置」三项一级导航代替实际目录。无会话、无工作区和搜索无结果有各自准确空态，目录读取失败保留重试。

Android 话题标题比工作区目录标签轻缩进 12dp，空闲、运行与审批使用同一固定状态槽；正在进行显示转圈，审批提醒优先，状态变化不挤动标题。底部固定带电脑连接状态的齿轮「设置」入口，目录在顶部与底部之间独立滚动。侧栏宽度适配 320px 窄屏并保留遮罩关闭区，不用 90% 大圆角卡片。打开和关闭不改变当前会话、文字草稿或滚动位置；打开时焦点留在侧栏，关闭恢复触发器。

聊天保留紧凑顶栏，菜单、Git、标题与新会话在实际可用宽度内压缩，不互相覆盖。空白草稿使用真实品牌头像、问候和工作区选择，不沿用简笔鲸鱼。长目录、全文搜索和复杂 Git 任务可使用独立可返回表面，返回不重放写请求。

## 输入区

常驻输入卡尽量接近桌面 InputBar：22px / 22dp 圆角、细边、基线背景、无外投影；多行编辑在上、工具轨在下。附件在左，模型、权限、计划与发送 / 停止在同一组可达工具区；窄屏可将文字轨与操作轨分行。模型长名省略时保留完整无障碍名称，发送按钮不能被挤掉。编辑文字 16px / 16sp，正文 14/22、辅助 12/18，控件保持母文档数值；Web 点击目标至少 44px，Android 至少 48dp，可用透明命中区补足。

输入随可用高度增长并在上限内滚动；软键盘出现后工具与发送仍完整可见，避免安全区和 IME 重复留白。消息区在输入区上方结束，不从透明输入卡下面穿过。长草稿可收起阅读，恢复编辑保留草稿与选区。运行、只读、审批接管和失败态保持既有能力；审批不能把发送操作留在背景可点区域。

## 弹窗与返回

模型、思考强度、权限、附件来源和行菜单跟随触发按钮展开，采用桌面 Menu 的 12px / 12dp 圆角、紧凑行和透明外部关闭区，不使用居中对话框或整页灰色模糊遮罩。模型菜单优先从入口上方向上浮出、右边对齐；可视窗口不足时避让边缘并限高滚动，旋转、输入卡变化和软键盘改变可视区域时重新定位。下钻在同一菜单内替换内容，保留返回入口；点击外部或在根层按 Escape 关闭。重命名、新会话选择和简短设置继续用按内容决定高度的紧凑 Modal，目录浏览、长搜索结果、完整设置和复杂 Git 表单使用可返回的任务面，破坏性操作用居中确认。Android 完整设置按电脑与连接、外观与阅读、对话、模型与权限、归档会话、当前会话用量、关于分区，并可搜索。新电脑配对放在设置的电脑与连接中，对话三点菜单只承载对话与工作区操作。

Web 复用 `ui/surfaces.js` 的焦点、滚动和导航边界；Android 的输入选择器使用锚定 Compose Popup，编辑及确认使用 Dialog，侧栏使用贴边 drawer，聊天继续挂载。背景层不可点击或聚焦。返回先收 IME，再退当前选择层；关闭恢复触发器但不强制唤起编辑键盘。history 不写入凭据或草稿，不在返回时重放业务写请求。操作反馈不挤动正文；减弱动态直接落位，动画只使用既有 transform/opacity token。

## Android 原生聊天迁移

Android 配对后的聊天、分页时间线、审批、工作区与会话管理、Git 和设置均由 Kotlin + Jetpack Compose 绘制。协议客户端保持既有 offer v2、E2EE 和设备证明，凭据进入加密存储，UI 不接收 deviceSecret 或可执行 HTML。APK 不内嵌 SPA；唯一升级读取器在旧稳定 asset origin 空白页读取凭据与文字草稿，禁止网络，迁移后销毁，失败不标记成功。

Web 和 Android 分轨验证。构建、单测、受控浏览器截图只能证明对应的实现与场景；公网配对、真实设备相机、IME 和流式对话结果必须按实际执行情况报告，不继承历史结果为本轮通过。
